# Bookingnefilo

Aplicación minimal para reservar entradas de cine.

- Nombre: Bookingnefilo
- Tech: Next.js + TypeScript
- API routes: /api/movies, /api/reservations

Scripts:
- npm run dev
- npm run build
- npm run start
- npm test

Deploy: listo para desplegar en Vercel (basta conectar el repo y usar el comando de build: `npm run build`).
